🚀 Cách dùng

  • Mở file code trong editor → gõ vài ký tự → popup suggestion tự hiện.
  • Nhấn ↑ / ↓ để di chuyển, Enter hoặc Tab để chấp nhận.
  • Ctrl + Space để trigger thủ công.
  • Vào Settings → Modules → code_suggest để tinh chỉnh.
